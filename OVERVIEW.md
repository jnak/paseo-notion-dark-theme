Notion Dark adds a dark theme to Paseo built from the colors of Notion's dark theme. The values were read from the Notion desktop app's own color tokens: Notion's near-black page and sidebar grays, its warm off-white and gray text, soft borders, and Notion blue as the accent. Surfaces step up in the same order as Paseo's built-in dark theme, so the sidebar sits on Notion's page color and the chat area on its sidebar color, the reverse of Notion itself. Accent buttons use dark text on Notion blue, which Paseo sets for every dark theme. Diff colors, status dots, and the composer outline stay Paseo's defaults, because themes cannot change them. The theme appears under Settings → Appearance. It contains theme data only: no settings, no server component, and no network or file access. Requires Paseo 0.11.0 or later.
